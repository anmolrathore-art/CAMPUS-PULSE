## PROJECT TITLE

# Campus Pulse - Student Activity Analyzer

## Overview
Campus Pulse is a Python console app for students to monitor study patterns by reading in and outputting data about study hours, homework, working load, feeling prepared for exams, sleep hours, and subjects studied, and then computing outputs of interest.
## Features
* Add daily study entries
* View a study dashboard
* View study history
* Analyze subjects
* Get today's priority
* Delete the last entry
* Basic input validation
## Technologies / Tools Used
* Python 3
* VS Code or any Python IDE
* Python built-in datetime module
## Installation & Run
* Install Python 3.
* Download or copy the project files.
* Open the project folder in VS Code or Terminal.
* Run:
* python "Pasted code.py"
## Testing

## Limitations
* Program's data is temporary, and it is not saved after execution.
* It is a console-based application.
* There is no database used and no storage.
