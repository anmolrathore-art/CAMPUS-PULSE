# Campus Pulse - Project Statement

## Problem Statement

* It's easy to lose track of study time, coursework, workload, confidence, sleep and subject. Campus Pulse offers an easy way to log this information and will give an overview of your study.

## Scope of the Project

* This project is about tracking students activities in a day. I will record every activities for student through a very simple Python console app. The program will output student's activities summary, subject analysis and few primary priorities.

## Target Users

* School and college students

* Students preparing for exams

* Students interested in tracking their studying habits

## High-Level Features

* Add daily study entries

* View dashboard and study statistics

* View study history

* Analyze study time by subject

* Get today's priority

* Track workload, confidence, and sleep

* Delete the last entry

* Validate user input
